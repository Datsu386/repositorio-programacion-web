##  Tecnologías

Las principales tecnologías contempladas dentro de la materia son:

* **HTML** — Estructura y contenido de páginas web.
* **CSS** — Diseño y presentación.
* **JavaScript** — Programación e interactividad.
* **Servidores** — Conceptos relacionados con el funcionamiento de aplicaciones web.
* **Programación del lado del servidor** — Desarrollo de la lógica que se ejecuta en el servidor.
